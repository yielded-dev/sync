## Choose your setup

Start with the [installation guide](./guide/getting-started.md), then choose a
[host and persistence adapter](./reference/packages.md). Core contracts work on
both server and client; platform integrations stay in separate packages.

The [counter example](./api/consumer.md) shows how to implement a source.
The [client guide](./client.md) covers sessions, persistence, retries, and Atom
bindings. For a complete frontend and Worker, run the
[React board](https://github.com/yielded-dev/sync/tree/main/examples/list-board).
