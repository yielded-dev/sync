Sync keeps your clients up to date with the data on your server. Connect a client
to a Sync source and it receives the current state, follows live changes, and
reconnects and catches up after a disconnect.

Your app decides what data to share and who can access it. Sync handles initial
loading, update delivery, version tracking, and recovery.

## Keep your UI current

Once the [client is connected](./getting-started.md#connect-a-client), your
components can render its data. Server changes update the replica and rerender
the component automatically:

```tsx title="App.tsx"
import { RegistryProvider, useAtomValue } from "@effect/atom-react";

import { counter } from "./counter-atoms";

function CounterValue() {
  const replica = useAtomValue(counter.replica);

  if (replica._tag === "Failure") {
    return <p role="alert">Could not load the counter.</p>;
  }
  if (replica._tag !== "Success") {
    return <output>Connecting…</output>;
  }

  return <output>{replica.value.value?.value ?? "Connecting…"}</output>;
}

export function App() {
  return (
    <RegistryProvider>
      <CounterValue />
    </RegistryProvider>
  );
}
```

## Reconnect and catch up

Sync tracks which version each client has seen. After reconnecting, it replays
missed updates or loads a fresh snapshot if that history is no longer available.
Your components keep reading the same replica throughout.

## Send edits back

Clients can also send typed actions to the server. An optimistic reducer shows an
edit immediately, before the server replies. Sync confirms the edit if it's
accepted or rolls it back if it's rejected.

If a reply is lost, automatic retries use the original command identity so the
server doesn't apply the same edit twice. With IndexedDB persistence, pending
edits survive reloads. Unresolved edits stay available through the
[recovery controls](../client.mdx#retry-and-recovery) for your app to resolve.

## Built for Effect

Effect Schema defines your shared state, actions, results, and errors. Server
handlers are Effects, and client bindings work with Effect Atom and React.
Use the Cloudflare and IndexedDB adapters or supply your own storage and transport.
